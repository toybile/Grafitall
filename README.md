# Grafitall
O projeto é um sistema web de organização para a empresa "Grafitall".
A mesma é dona de uma fábrica, ao qual requisita de um sistema online para melhorar a organização, sobretudo, dos seguintes aspectos:
- Produção de grafite
- Estoque de grafite
- Clientes

# Entidades
- Producao
- Estoque
- Cliente

# Tecnologias
O sistema web utilizará a tecnologia JSP, Gson, JSON, com o servidor do Tomcat.
